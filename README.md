# Vereda Connect

Quiero generar el esqueleto inicial de AlertaVereda, una plataforma web

comunitaria de prevención y alertas para las veredas rurales de Ebéjico,

Antioquia (Colombia). Incluye estos módulos: Emergencias, Vías, Servicios,

Avisos y Reportar, con dos tipos de usuario (habitante y

administrador/Junta de Acción Comunal), diseño mobile-first, y estos colores

exactos: verde bosque #2F5D45, papel kraft #EDE6D3, dorado #C99A2E,

terracota #A8472E, y los colores de severidad rojo #C23B2E / naranja #DB7B33

/ verde #3C8A5B. Incluye un botón fijo de "Llamar a emergencias · 123"

siempre visible en pantalla.

Genera la base de frontend + backend + autenticación de los dos roles, y la

estructura de datos para los 5 módulos. No necesito que quede lista para

producción todavía — esto se va a revisar y refinar después por Cursor y por

Claude.
