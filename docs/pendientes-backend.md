# Pendientes de backend — AlertaVereda

Registro resumido de necesidades detectadas durante los Módulos 1 y 2. No modifica Supabase, Auth, Storage, RLS, Edge Functions, SQL ni migraciones.

El detalle técnico, las reglas de visibilidad, la protección de evidencias, la continuidad de Reportar y las dependencias de implementación están en [Módulo 2 — Auditoría técnica de reportes, Reportar y dependencias](modulo-2-auditoria-reportar-dependencias.md). Este archivo debe conservar solo el inventario corto de pendientes y enlazar al detalle, sin duplicarlo.
